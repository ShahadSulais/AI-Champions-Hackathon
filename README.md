# Knowledge Guardians | حُرّاس المعرفة

**Knowledge Guardians** is an AI-powered adaptive learning experience that transforms educational content into interactive story-based adventures using Google Gemini.

Users provide learning material, and Gemini analyzes the key concepts, generates a story, selects suitable educational mini-games, and creates adaptive learning paths based on performance.

## How It Works

1. The user provides learning content.
2. Gemini extracts key concepts and learning objectives.
3. The content is transformed into an interactive story.
4. Each concept is mapped to a suitable mini-game.
5. The learner progresses by completing educational challenges.
6. The experience adapts based on the learner's performance.
7. A personalized learning summary highlights strengths and concepts that need review.

## Adaptive Learning

The experience responds to the learner's understanding:

- **Mastered:** Progresses to more advanced challenges.
- **Uncertain:** Receives additional examples or support.
- **Misconception Detected:** Enters a short remedial scene and is reassessed.

This allows each learner to follow a path that reflects their actual understanding.

## Mini-Games

The platform uses reusable game templates rather than generating new game code for every lesson.

| Mini-Game | Purpose |
|---|---|
| Drag & Drop | Identify and organize concepts |
| Classification | Compare and categorize |
| Sequencing | Understand processes and order |
| Matching | Connect related concepts |
| Find the Error | Detect mistakes and misconceptions |
| Evidence Selection | Support claims with evidence |
| Written Response | Evaluate deeper understanding |

Gemini selects the appropriate game based on the learning objective and generates its content.

## Google Gemini

Gemini powers the intelligent layer of the experience by:

- Analyzing educational content
- Extracting concepts and objectives
- Generating stories, scenes, and dialogue
- Selecting suitable mini-games
- Generating challenge content
- Creating adaptive and remedial paths
- Supporting personalized learning insights

The game mechanics remain pre-built and reusable, allowing the same system to work with different subjects and learning materials.
