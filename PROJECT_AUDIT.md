# Project Audit: حُرّاس المعرفة

## 1. Existing Prototype Overview
The current prototype (`ai_studio_code (5).html`) is a single-file Arabic RTL web application for an adaptive educational game called **"حُرّاس المعرفة"**.

### Key Features Implemented:
- **Teacher Setup Screen (`#screen-setup`)**: Allows inputs for Lesson Title, Student Level/Age, Lesson Text, and Story Theme selection (Future City, Fantasy World, Space Journey, Detective Mystery). Includes a demo button that populates sample data on Photosynthesis.
- **Story Intro Screen (`#screen-intro`)**: Displays generated adventure metadata (Title, Mission, Character guide, dialogue, and TTS speech synthesis button).
- **Active Gameplay Screen (`#screen-game`)**: Renders 3 sequential minigame challenges:
  1. **Classification (`classification`)**: Interactive drag-and-click item assignment to categories with unassign support.
  2. **Ordering (`ordering`)**: Up/down reordering controls for sequential steps.
  3. **Written Answer (`written_answer`)**: Open-ended question input with adaptive difficulty adjustment on Scene 3 based on student struggle history.
- **Ending & Results Screen (`#screen-ending`)**: Summarizes mastered concepts vs. concepts for review, and persists progress to adaptive memory.
- **Teacher Diagnostic Dashboard (`#screen-report`)**: Displays summary of completed sessions, strengths, weak areas, and printing support.
- **Adaptive Memory Inspector Modal**: Accessible via header button, manages profile summary, history timeline, and reset functionality in `localStorage` (`knowledge_guardians_adaptive_memory_v4`).
- **Audio & Sound**: Synthesized audio cues via Web Audio API oscillators and Arabic TTS via SpeechSynthesis API.

---

## 2. Why AI Generation Does Not Work
- **Explicit Finding**: The `generateAdaptiveGame()` function (line 520 in `ai_studio_code (5).html`) is **entirely hard-coded**.
- It uses string matching on the lesson text/title (`text.includes("البناء الضوئي") || title.includes("البناء الضوئي")`).
- If "البناء الضوئي" is present, it returns a hardcoded 3-scene Photosynthesis game structure.
- If any other lesson is entered, it returns static placeholder templates ("مغامرة...", "المفهوم الأساسي الأول", "عنصر رئيسي أ", "الخطوة الأولى").
- There is **no backend server**, **no Google Gemini API client**, **no prompt template**, and **no server-side API key handling**.

---

## 3. Existing Bugs & Fragile Areas
1. **Hardcoded Logic**: Cannot generate games for arbitrary lesson inputs.
2. **Security Risk if Unchecked**: Any direct browser API call would leak the Gemini API key to the client.
3. **Fragile Written Answer Validation**: Evaluates written answers purely by text length (`studentText.length > 5 ? 80 : 30`) without semantic validation.
4. **Monolithic Architecture**: 1122 lines of HTML, CSS, DOM logic, state management, audio generation, and mock game logic combined in a single file.
5. **Disabled Features / Placeholders**: PDF upload button is disabled ("رفع PDF — قريبًا").
6. **External CDN Dependencies**: Relies on external CDN scripts for Tailwind CSS and Google Fonts without offline fallbacks.

---

## 4. Proposed Minimal Architecture
```
[ Browser / Frontend ] (HTML/CSS/JS - RTL UI, LocalStorage Memory, Audio Engine)
         │
         │  POST /api/generate-game (JSON: title, age, text, theme, memory)
         ▼
[ Express Node.js Server ] (Holds GEMINI_API_KEY server-side)
         │
         │  Gemini API Call (Structured JSON Output Prompt / Schema)
         ▼
[ Google Gemini API ]
```

## 5. Proposed File Structure to Create / Extract
- `package.json` - Node.js dependencies (`express`, `@google/genai`, `dotenv`, `cors`).
- `.env.example` & `.env` - Server environment variables (`GEMINI_API_KEY`, `PORT`).
- `server.js` - Express backend with `/api/generate-game` endpoint, prompt builder, and structured JSON parsing.
- `public/index.html` - Clean Arabic RTL layout extracted from prototype.
- `public/js/app.js` - Main application logic, screen routing, and API integration.
- `public/js/memory.js` - Adaptive memory management module (localStorage).
- `public/js/minigames.js` - Minigame rendering and evaluation engine.
- `public/js/audio.js` - Web Audio API sound effects and Web Speech API TTS wrapper.

---

## 6. Exact Acceptance Criteria for the MVP
1. **Dynamic AI Generation**: Teacher enters any custom lesson title, age group, text, and theme, and the backend returns a fully structured 3-scene adventure generated by Gemini.
2. **Server-Side API Security**: Gemini API key remains 100% server-side and is never exposed in client code, committed files, logs, or error responses.
3. **Gameplay Continuity**: Student completes all 3 challenges (Classification, Ordering, Written Answer) powered by the generated JSON payload.
4. **Adaptive Experience & Feedback**: Hints, feedback, success/support narrations, and adaptive question difficulty adjustments work as intended.
5. **Ending & Teacher Report**: Results screen accurately categorizes mastered vs. review concepts, updates localStorage memory, and displays the teacher diagnostic report.
6. **Arabic RTL Preservation**: Interface remains completely in Arabic with proper UTF-8 encoding and RTL visual alignment.
